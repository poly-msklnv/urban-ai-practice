# Проверка браузерной модели

`reference-cases.json.gz` — 10 независимых сценариев, рассчитанных оригинальным
`competitive_provision` из BlocksNet 1.0.0a9 / CBC на сохранённых входах.
Для каждого квартала сохранены все 10 колонок исходного метода, а также итоговые суммы.
Это тестовые эталоны, не данные сценария пользователя.

`tests/test_pages_model.mjs` сравнивает с ними браузерную реализацию, затем проверяет все
1039 размещений одной школы на 600 мест по полному рейтингу Python. Отдельно проверены
нулевой сценарий, исходный baseline, несколько школ в одном квартале, невалидные ID и вместимости.
Результат последнего прогона — `validation.json`.

Сборка требует Python только при подготовке файлов; опубликованное приложение использует
HiGHS WebAssembly в Worker. Исходная Python-реализация остаётся эталоном и не изменена.
