# Демонстрация приложения

[Видео MP4, 1:33](school-placement-demo.mp4) — реальная запись работы приложения
с подложкой Esri, русские субтитры встроены в кадр. Без звуковой дорожки.
[Отдельный SRT](school-placement-demo.srt).

Показаны исходное состояние, сценарий А (600 мест), карта изменений, сценарий Б (300+300),
сохранение и сравнение, CSV, полный автоматический перебор всех 1039 кварталов,
просмотр варианта из рейтинга и сброс. Все варианты одной школы равноценны по суммарной цели.

Технически: headless Google Chrome 156, Playwright/CDP screencast, запись реального экрана
1440×1000, кодирование FFmpeg H.264 в MP4 1440×1080 с отдельной полосой субтитров.
Ожидание поиска ускорено в 20 раз и подписано; остальные действия показаны в обычном темпе.
Перебор реально завершился 1039/1039 без ошибок. Запись не содержит вымышленных результатов.

Параметры, таймкоды и контрольная сумма — в [provenance.json](provenance.json).
Установка дополнительных программ для записи не потребовалась; использованы имеющиеся
Chrome, Playwright и FFmpeg. Браузерный сценарий приёмки: ../../tests/browser_school_placement.cjs.
