# Скриншоты приложения

Реальные full-page PNG из headless Google Chrome 156 на сервере, Playwright, 13.11.2026.
Исходное состояние, карта Esri World Light Gray, кварталы и показатели из сохранённой практики 2.

- `desktop-esri.png`: viewport 1440×1000.
- `mobile-esri.png`: viewport 390×844; масштаб и атрибуция разведены по ширине.

Это скриншоты интерфейса, без генеративной обработки. Картографическая атрибуция сохранена
внутри карты. Эмуляция размеров окна не заменяет проверку физического телефона и Safari.
